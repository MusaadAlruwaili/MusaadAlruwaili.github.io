## Problem and contribution
- [ ] State the engineering problem, baseline, and measurable contribution.
- [ ] Distinguish prior work from the proposed method and cite original sources.
- [ ] State assumptions, operating constraints, and limitations.

## Evidence and reproducibility
- [ ] Record dataset origin, permission, units, missing-data treatment, and split dates.
- [ ] Prevent leakage: fit preprocessing only on training data.
- [ ] Compare meaningful baselines using the same evaluation conditions.
- [ ] Record parameters, software versions, seeds, and hardware where relevant.
- [ ] Report uncertainty and failure cases; do not present illustrative data as field results.
- [ ] Link claims to figures/tables with readable labels and units.
