التحكم بمرحل باستخدام ESP32: تجربة تعليمية

تجربة عربية للتحكم بمرحل من المنفذ التسلسلي، مع كود قابل للتحميل وملاحظات التوصيل واختبار المنطق.

ماذا ستتعلم؟

  • ربط أمر برمجي بحالة خرج GPIO.
  • ضبط الفرق بين المرحل الفعّال بالمستوى المنخفض والمرتفع.
  • توثيق خطوات اختبار بسيطة يمكن تكرارها.

المتطلبات السابقة: Arduino IDE وحزمة لوحات Espressif ولوحة ESP32 ووحدة مرحل موثقة متوافقة مع منطق ٣٫٣ فولت.

فكرة التجربة

يرسل ESP32 إشارة تحكم إلى وحدة المرحل. يفصل المرحل أو يصل دائرته الخارجية وفق تصميمه. نبدأ بالتعرف إلى استجابة الوحدة دون توصيل حمل إلى أطراف التلامس، ونستخدم منفذ Serial Monitor لإرسال أوامر واضحة.

هذه تجربة تعليمية وليست وحدة حماية أو متحكمًا صناعيًا. لم يُختبر المثال على عتاد فعلي ضمن هذا التحديث.

التوصيل والتحقق من المكونات

  • افصل التغذية قبل التوصيل، وتحقق من مخطط لوحتك. يستخدم المثال GPIO 23 على لوحة ESP32 DevKit التقليدية؛ وقد يلزم تغييره للوحات أخرى.
  • صِل خرج التحكم بمدخل الوحدة فقط إذا كان موثقًا بأنه متوافق مع ٣٫٣ فولت. لا تقد ملف المرحل مباشرة من منفذ GPIO، ولا تدخل ٥ فولت إليه.
  • غذِّ الوحدة وفق وثائقها، واتبع متطلبات الأرضي والعزل الخاصة بها بدل افتراض توصيل جميع نقاط الأرضي.
  • اترك أطراف حمل المرحل دون توصيل في الاختبار الأول. هذه الصفحة لا تتناول توصيل جهد الشبكة الكهربائية.

الكود وأوامر التشغيل

بعد الإعداد يضع البرنامج الخرج في حالة OFF. أرسل 1 للتشغيل و0 للإيقاف. تُتجاهل الأحرف الأخرى ونهايات الأسطر. اضبط سرعة Serial Monitor على 115200.

// ESP32 low-voltage relay bench demo. No Wi-Fi or credentials required.
// Classic ESP32 DevKit example: verify your board's GPIO map before wiring.
#include <Arduino.h>
constexpr uint8_t RELAY_PIN = 23;
constexpr bool ACTIVE_LOW = true;  // Match the relay module datasheet.
constexpr uint8_t RELAY_ON = ACTIVE_LOW ? LOW : HIGH;
constexpr uint8_t RELAY_OFF = ACTIVE_LOW ? HIGH : LOW;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, RELAY_OFF); // Request OFF immediately after output setup.
  Serial.begin(115200);
  Serial.println("Bench demo: 1=ON, 0=OFF. Starts OFF.");
}

void loop() {
  if (Serial.available() > 0) {
    const char command = Serial.read();
    if (command == '1' || command == '0') {
      const bool on = command == '1';
      digitalWrite(RELAY_PIN, on ? RELAY_ON : RELAY_OFF);
      Serial.println(on ? "Relay ON" : "Relay OFF");
    }
  }
}

غيّر ACTIVE_LOW وفق وثائق الوحدة. يضبط البرنامج مستوى الإيقاف مباشرة بعد تهيئة الخرج. هذا لا يضمن حالة آمنة خلال التهيئة أو الإقلاع أو إعادة التشغيل أو انقطاع التغذية؛ تتطلب الأحمال ذات العواقب حماية عتادية مناسبة.

الخلاصة والخطوة التالية

  • تحقق من توافق المنطق ورقم المنفذ قبل الرفع.
  • ابدأ دون حمل ووثّق كل أمر ونتيجته.
  • الحالة البرمجية الافتراضية لا تغطي أعطال التغذية والإقلاع.
