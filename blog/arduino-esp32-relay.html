Control a Relay with ESP32

A practical starting point for students and engineers who want to control real-world devices with an ESP32.

What you will learn

  • Map a software command to a documented GPIO state.
  • Handle active-low and active-high relay logic explicitly.
  • Record repeatable low-voltage bench checks.

Prerequisites: Arduino IDE, the Espressif ESP32 board package, and a documented 3.3 V logic-compatible relay module.

What the relay does

A relay lets a low-voltage controller switch a separate circuit. In a simple learning project, the ESP32 sends a control signal to a relay module, and the relay opens or closes the output circuit. This is the same basic idea behind many automation tasks: a digital controller makes a decision, then an interface device safely switches a load.

The ESP32 is useful because it combines GPIO control, Wi-Fi, Bluetooth, low cost, and a large learning ecosystem. A relay project can begin as a simple on/off exercise and later grow into a smart-home controller, pump controller, alarm output, sensor-triggered actuator, or MQTT-connected industrial prototype.

Basic build steps

  • Choose an ESP32 development board and a compatible relay module.
  • Connect VCC, GND, and a GPIO control pin according to the module documentation.
  • Write a simple GPIO program that turns the relay on and off.
  • Test with a low-risk load first before connecting anything sensitive.
  • Add MQTT, a web dashboard, or sensor logic when the basic control is stable.

A common learning setup uses a 5 V relay module powered from a suitable supply, a shared ground with the ESP32 when required by the module design, and one GPIO pin connected to the relay input. Some relay modules are active-low, meaning the relay turns on when the GPIO is pulled low. Always check the module documentation before assuming the logic direction.

Worked example: command a relay from Serial Monitor

Low-voltage bench example. Verify the board pinout, input compatibility, and relay polarity. The sketch has not been tested on physical hardware.

The downloadable program starts OFF after setup and accepts 1 for ON or 0 for OFF through Serial Monitor at 115200 baud. It ignores other characters. Begin with load terminals disconnected.

// ESP32 low-voltage relay bench demo. No Wi-Fi or credentials required.
// Classic ESP32 DevKit example: verify your board's GPIO map before wiring.
#include <Arduino.h>
constexpr uint8_t RELAY_PIN = 23;
constexpr bool ACTIVE_LOW = true;  // Match the relay module datasheet.
constexpr uint8_t RELAY_ON = ACTIVE_LOW ? LOW : HIGH;
constexpr uint8_t RELAY_OFF = ACTIVE_LOW ? HIGH : LOW;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, RELAY_OFF); // Request OFF immediately after output setup.
  Serial.begin(115200);
  Serial.println("Bench demo: 1=ON, 0=OFF. Starts OFF.");
}

void loop() {
  if (Serial.available() > 0) {
    const char command = Serial.read();
    if (command == '1' || command == '0') {
      const bool on = command == '1';
      digitalWrite(RELAY_PIN, on ? RELAY_ON : RELAY_OFF);
      Serial.println(on ? "Relay ON" : "Relay OFF");
    }
  }
}

The program requests the inactive level immediately after configuring the output. This does not guarantee a safe state during initialization, boot, power loss, or reset; those states require suitable hardware design.

Good engineering habits

Even small embedded projects benefit from engineering discipline. Label wires, document the GPIO pin, write down the relay module type, and keep a simple test log. If the project later includes a sensor, dashboard, or cloud connection, these notes prevent confusion when troubleshooting.

For IoT extensions, MQTT is a practical next step. The ESP32 can subscribe to a topic such as `lab/relay1/cmd` and publish its status to `lab/relay1/state`. This creates a clean separation between command, device behavior, and monitoring. It also prepares the project for dashboards, automation rules, and data logging.

Safety note

Do not connect mains voltage unless you are qualified and using proper protection, enclosures, isolation, fusing, strain relief, and local electrical safety practices. For learning, start with low-voltage DC loads such as a small lamp, buzzer, or motor. Keep the control side and load side clearly separated, and never touch wiring while a circuit is energized.

A relay is simple, but the load it controls may not be. Motors, pumps, and inductive loads can create electrical noise and voltage spikes. Use appropriate protection components and choose relay ratings with margin. When the project moves beyond a classroom demonstration, involve a qualified electrical professional.

Key takeaways

  • Match the pin and active level to the exact board/module.
  • Start with unloaded contacts and record each command response.
  • Software defaults do not replace hardware fault protection.
